# Bush V2

A crude hand-drawn fat-marker font. Every glyph looks like a kid drew it with
a marker — jittery strokes, uneven pressure, rough lumpy edges, letters that
can't sit still. Built for the **In the Bushes** locked art style
(kid-drawing, crude lo-fi, handmade deadpan).

This is the rebuild of the original Bush (v1), which came out too clean and
was rejected. V2 is drawn stroke-by-stroke as overlapping marker dabs with
positional jitter, pressure variation, dry-brush skips, and ink speckle —
genuinely crude, on purpose.

**Status:** Built 2026-10-10. Awaiting owner review.

## What's inside
- `BushV2-Regular.ttf` — the typing font (A–Z, 0–9, `! ? . , ' - &`;
  lowercase auto-maps to caps; space included)
- `png/` — 43 transparent-background glyphs (black ink)
- `SPECIMEN.png` — sales/type specimen card
- `work/gen_bushv2.py` — the generator (fontTools, no tracing step;
  deterministic per-glyph seeds, so rebuilds are identical)

## Install
- **Android:** zFont 3 → install the TTF → pick "Bush V2"
- **Windows/Mac/Linux:** double-click the TTF → Install
- **Design apps:** drop the TTF in, or use the PNG pack directly
