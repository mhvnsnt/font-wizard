# BLOCK BURNER

Heavy graffiti-tag display font — sharp aggressive strokes, street energy.
Family #2 from the Font Wizard foundry.

## What's inside
- `BlockBurner-Regular.ttf` — the installable font (A–Z, 0–9, `! ? . , ' - &`)
- `png/` — 43 transparent-background glyph PNGs at 2000px tall (white ink)
- `SPECIMEN.png` — sales/display card

## Install
- **Android:** download the TTF, open with zFont 3 (Play Store) → Local → install. Or point your design app's font uploader (PicsArt, Canva, PixelLab) at the file.
- **Windows:** right-click the TTF → Install.
- **Mac:** double-click the TTF → Install Font.
- **Linux:** copy to `~/.fonts/` and run `fc-cache -f -v`.
- **iOS:** use a font installer app (e.g. iFont) to install the TTF profile.

Lowercase letters map to the same caps glyphs.
