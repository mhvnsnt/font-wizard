# Trippy Drippy Wizard

The official Wizard Gang drippy psychedelic bubble-lettering, as a real font.
Built from the custom Wizard Gang card artwork — fat melting bubble letters
with hand-drawn doodle interiors (spirals, paisleys, stars, clouds).

**Version 1.0** — 43 glyphs: `A–Z` (+ lowercase mapped to caps), `0–9`,
`! ? . , ' - &`, space.

## What's in this pack

| File | What it is |
|---|---|
| `TrippyDrippyWizard-Regular.ttf` | Installable typing font (install below) |
| `png/` | 43 transparent-background PNGs, 2000px tall, white ink — for designers who want the artwork directly |
| `SPECIMEN.png` | Type specimen / sales card showing the full character set |

## Install the font

**Windows:** Right-click `TrippyDrippyWizard-Regular.ttf` → **Install**.
Or drag it into `Settings → Personalization → Fonts`.

**macOS:** Double-click the `.ttf` → **Install Font** (opens in Font Book).

**Linux:** Copy to `~/.fonts/` (or `~/.local/share/fonts/`), then run
`fc-cache -f`.

**Android:** The TTF works in apps that accept custom fonts (e.g. Phonto,
PixelLab). Copy it to the phone and import inside the app.

**iOS:** Install via a font-manager app (e.g. iFont) or a design app that
imports TTFs.

Then pick **"Trippy Drippy Wizard"** in any app's font list and type.

## Using the PNG pack

Every glyph is a transparent PNG at 2000px tall (`png/TDW-A.png`, …).
White artwork — drop it on any dark background, or invert for light
backgrounds. Punctuation files: `TDW-exclaim`, `TDW-question`,
`TDW-period`, `TDW-comma`, `TDW-apostrophe`, `TDW-hyphen`, `TDW-ampersand`.

## Notes

- All-caps display face: typing lowercase gives the same cap glyphs.
- Glyph sources: extracted from Wizard Gang card art (A D E G I K N O P R T W Z)
  and the TRIPPEDD NETWORK render; remaining letters, digits, and punctuation
  drawn in the same style to complete the set.
