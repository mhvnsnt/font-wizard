# Trippy Drippy Wizard

The first Font Wizard family. Custom drippy psychedelic bubble lettering
from the Wizard Gang title card — fat wavy letterforms, doodle interiors
(swirls, paisleys, stars, dots, clouds), melty drips.

**Status:** build in progress (checkpoint `wg-font-pack.json`).
Landing here: `TrippyDrippyWizard-Regular.ttf` + `.woff`/`.woff2`,
transparent PNG glyph pack, `SPECIMEN.png`.

## Planned contents
- A–Z, 0–9, basic punctuation
- TTF / WOFF / WOFF2
- `png/` — 2000px transparent glyphs for designers
- `SPECIMEN.png` — sales card
